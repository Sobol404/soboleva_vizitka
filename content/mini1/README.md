# `mini1`: правило публикации

`source.html` — канонический снимок короткого рекламного лендинга из
`Visa/landing-visa`. React подключает его по адресу `/mini1` и отправляет обе
кнопки в рекламируемый Telegram-канал из `config/links.ts`.

По явному разрешению владельца 2026-09-12 эта переходная версия опубликована
в production вместе с остальным сайтом. Это не отменяет требования заменить
материалы ниже в следующем согласованном обновлении:

- видеоскринкаст, баннер и фото Ирины явно помечены плейсхолдерами;
- при получении медиа нужно заменить именно эти плейсхолдеры подтверждёнными
  материалами;
- нельзя самовольно менять цифры и обещания страницы.
