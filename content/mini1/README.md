# `mini1`: правило публикации

`source.html` — канонический снимок исходного короткого рекламного лендинга из
`Visa/landing-visa`. Рабочая React-вёрстка страницы находится в
`components/MiniLanding.tsx`, стили — в `components/MiniLanding.css`.
Страница доступна по адресу `/mini1` и отправляет обе кнопки в рекламируемый
Telegram-канал из `config/links.ts`.

По явному разрешению владельца 2026-09-12 эта переходная версия опубликована
в production вместе с остальным сайтом. Это не отменяет требования заменить
материалы ниже в следующем согласованном обновлении:

- видеоскринкаст подключается из `/media/videos/safe-case-mini-hero.mp4`;
- исходный видеофайл нужно положить для проверки в `Visa/media-inbox/videos/`;
- после проверки утверждённая копия переносится в `public/media/videos/` с этим
  именем;
- фото для блока «Автор статьи» подключается из
  `public/media/pages/mini1/irina-about.jpg`;
- второй экран не использует отдельный баннер, на нём остаётся компактный список;
- нельзя самовольно менять цифры и обещания страницы.

## Согласованная логика первого экрана

- порядок на мобильном: заголовок → подзаголовок → компактные буллеты → CTA →
  подтверждённая цифра `785` → видеопревью;
- видеопревью запускается без звука, повторяется по кругу и не показывает
  элементы управления;
- основная и наложенная на видео мобильная кнопки ведут в один Telegram-канал;
- на десктопе кнопка поверх видео скрыта;
- рядом с цифрой `785` показывается декоративная стопка нейтральных мини-аватаров;
- всплывающие уведомления на странице отключены.

## Детали вёрстки

- заголовок и подзаголовок первого экрана центрированы; название метода
  «Safe Case» выделено тем же голубым, что и цифра `9 из 10`, без цветной плашки;
- у буллетов предусмотрены очень мягкие hover-состояния: изменение длится `500ms`
  и не сдвигает карточку более чем на один пиксель;
- в блоке автора фотография на мобильном занимает всю ширину текстового контейнера;
- внизу мини-лендинга используется компактный вариант футера: бренд, реквизиты,
  город «Москва», контакты, соцсети и юридические ссылки собраны без отдельных
  заголовков; полный адрес регистрации не выводится.
