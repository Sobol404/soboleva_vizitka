# Как добавить новую статью

## Куда писать

Каждая обычная статья — отдельный файл в `content/articles/` с расширением `.md`.

Возьми за основу `../ARTICLE_TEMPLATE.md`, скопируй его и назови файл латиницей, например:

```text
content/articles/ds-160-mistakes.md
```

## Что обязательно заполнить

Верхняя часть файла между двумя строками `---` — это карточка статьи:

```md
---
title: "Заголовок"
slug: "ds-160-mistakes"
description: "Одно понятное предложение для карточки и поисковой выдачи."
date: "2026-09-01"
author: "Ирина Соболева"
cover: "/media/articles/ds-160-mistakes-cover.webp"
---
```

Затем идёт сам текст Markdown с подзаголовками, списками и картинками.

## Оглавление статьи

Заголовки второго уровня `##` автоматически попадают в закреплённое оглавление статьи. Делай их содержательными и не повторяй одинаковые заголовки в одном материале.

На десктопе оглавление постоянно находится в правой sticky-колонке под шапкой, на мобильном — открывается одной закреплённой кнопкой в нижней шторке. Отдельное меню или ручную разметку оглавления добавлять не нужно. Общий стандарт и проверка новых страниц описаны в [`../README.md`](../README.md#оглавление-документов-и-статей).

## Как посмотреть

1. Запусти `npm run dev` в папке `soboleva_vizitka`.
2. Открой главную страницу.
3. Новая статья появится в блоке «Блог» автоматически.
4. Нажми на карточку: адрес будет выглядеть так: `/article/ds-160-mistakes`.

## Что пока не подходит для обычного Markdown

Длинный продающий лендинг Safe Case, калькуляторы, сложные тарифы, интерактивные квизы и формы. Для них создаём отдельный React-шаблон, как `SafeCaseLanding.tsx`.
