# Safe Case: правило контентного паритета

`source.html` — канонический снимок продающего лендинга из папки `article-safe-case`.
Он подключается в React-маршрут `/usa-safecase` без сокращения текста.

## Что нельзя менять при техническом переносе

- заголовки, формулировки и порядок смысловых блоков;
- подробности кейсов, шагов, гарантий и расчёта стоимости отказа;
- оффер бесплатного разбора, ограничения слотов и путь CTA;
- изображения и подписи внутри блоков.

## Как обновлять лендинг

1. Отредактировать канонический текст и явно согласовать содержательные изменения.
2. Обновить `source.html` той же редакцией.
3. Проверить наличие всех локальных изображений в `public/media/safe-case/`.
4. Собрать сайт и проверить десктоп, мобильную версию, CTA и раскрывающиеся кейсы.
5. Только после проверки паритета публиковать новую версию.

Нельзя «улучшать», пересказывать или сокращать копирайтинг во время рефакторинга кода.
Разделение на React-компоненты выполняется постепенно и только с визуальным и текстовым сравнением с этим источником.
