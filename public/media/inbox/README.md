# Новые изображения для сайта

Сюда можно складывать новые или обезличенные изображения для замены на сайте.

Имена файлов могут быть любыми. После загрузки напишите в чате, какие блоки нужно обновить: например, «новый Hero», «обезличенные визы», «отзывы», «контактный мокап».

Перед заменой я сопоставлю изображения с текущими блоками, а прежний файл сохраню рядом с суффиксом `.old` — исходник не будет потерян.
