# Аналитика Яндекс Метрики

Счётчик: `100030291` для `zagranici.ru`.

## Принцип работы

- Сайт работает как SPA: при переходах Метрика получает виртуальные URL (`/blog`, `/article/...`, `/safe-case`), поэтому статьи не смешиваются с главной страницей.
- Вебвизор, карта кликов и карта скроллинга включены в коде. В интерфейсе Метрики должна быть включена настройка «Вебвизор, карта скроллинга, аналитика форм».
- Счётчик загружается только после выбора «Принять» в баннере cookie. При «Отклонить» Метрика не получает визит и события.
- Квиз Prodamus XL — единственный источник главных конверсий формы. Сайт не отправляет отдельные цели при прокрутке к квизу или внутри его iframe, поэтому отправка заявки не дублируется.
- В параметры целей не передаются имя, телефон, e-mail, содержание заявки или клиентские документы.

## Цели, которые нужно создать в Метрике

Все цели ниже создаются как «Целевое событие» с идентификатором из первого столбца.

| Идентификатор | Что означает |
| --- | --- |
| `ym-open-chat` | Открыт Telegram или MAX для связи с сайта |
| `social_telegram_click` | Переход в Telegram-канал |
| `social_instagram_click` | Переход в Instagram |
| `social_threads_click` | Переход в Threads |
| `social_tiktok_click` | Переход в TikTok |
| `social_youtube_click` | Переход в YouTube |
| `social_max_click` | Переход в MAX из блока соцсетей |
| `content_scroll_25` / `50` / `75` / `90` | Дочитывание длинного материала до указанной глубины |
| `content_engaged_30s` / `60s` / `120s` | Время активного чтения: вкладка видима, пользователь не ушёл с неё |
| `content_read_complete` | Не менее 90% материала и 60 секунд активного чтения |

Для точного анализа каждой статьи используй одновременно фильтр по виртуальному URL и отчёты «Время на сайте», «Глубина просмотра», Вебвизор и карту скроллинга.
