# Deployment notes

## Контуры

- **MacBook** — локальная рабочая копия: здесь вносятся изменения и проверяется preview.
- **Gitea** — основной Git-контур: `https://git.soboltraf.ru/`; для этого проекта remote `origin` — `Alex_Sobolev/safevisa`.
- **GitHub** — зеркало и резервная копия, не самостоятельный путь релиза.
- **control-nl** — удалённая среда разработки и Codex; не production-контур.
- **production-ru** — российский production-контур: сайт Visa обслуживается через существующий путь `deploy` и Caddy.

## Важно

Coolify установлен на `control-nl`, но его использование для деплоя поставлено на паузу. Не подключать к нему `production-ru`, не создавать для него Git-учётные данные или webhook и не публиковать через его proxy без отдельного пересмотра решения.

## Что требует подтверждения владельца

Нужны отдельные подтверждения перед commit/push, любым deploy или откатом, изменением DNS/Caddy/серверов, подключением Coolify, а также добавлением или изменением секретов. До подтверждения допустимы только локальные правки, preview и проверки.
