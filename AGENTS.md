# Project instructions

After changing copy, components, responsive styles, or interactions in this project, use the local `visa-site-qa` skill from `.agents/skills/visa-site-qa/SKILL.md` before reporting the work as complete.

The original approved marketing copy is content, not filler. Do not shorten, paraphrase, or replace it during technical migration unless the user separately approves the copy change.

A visual change is accepted only after checking both mobile and desktop layouts and exercising the affected interaction. The presence of CSS classes or horizontal overflow alone is not proof that swipe, sliders, buttons, or modals work.
